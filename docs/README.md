- Każda większa zmiana techniczna powinna aktualizować odpowiedni dokument.

- Jeżeli dokument opisuje planowany element, musi być to jasno oznaczone.
- Linki w tym pliku powinny być aktualizowane razem z dodawaniem nowych dokumentów.
