# Accessibility Guide

## Cel

Dokument definiuje standardy dostępności (WCAG) obowiązujące w aplikacji KidZone.

## Poziom docelowy

- WCAG 2.2 AA

## Wymagania

- Kontrast zgodny z WCAG.
- Wszystkie elementy interaktywne posiadają etykiety dostępności.
- Obsługa TalkBack.
- Obsługa Dynamic Type / dużych czcionek.
- Cele dotykowe minimum 48dp.
- Brak informacji przekazywanych wyłącznie kolorem.

## Formularze

- Komunikaty błędów są czytelne.
- Fokus przechodzi logicznie.
- Pola obowiązkowe są oznaczone.

## Multimedia

- Obrazy dekoracyjne są ukryte dla czytnika.
- Obrazy istotne mają opis.

## Testy

- TalkBack
- Powiększona czcionka
- Landscape
- Klawiatura Bluetooth (jeśli dotyczy)

## Checklist

- [ ] Kontrast poprawny.
- [ ] TalkBack działa.
- [ ] 48dp touch target.
- [ ] Dynamic font działa.
- [ ] Accessibility review zakończony.
